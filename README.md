# Mini Search Engine 🔎

A console-based Mini Search Engine developed in C++ that allows users to index text documents, search for keywords, calculate relevance scores, and rank matching documents.

## 🚀 Features

- Add and index individual `.txt` documents
- Search indexed documents using keywords
- Case-insensitive keyword searching
- Count keyword frequency
- Calculate relevance scores
- Rank search results by relevance
- View indexed documents
- Save search results to a text file
- Handle invalid or unavailable file paths
- Simple menu-driven console interface

## 🛠️ Technologies & Concepts

- C++
- Object-Oriented Programming (OOP)
- STL
- vector
- unordered_map
- String Processing
- File Handling
- Document Indexing
- Search Ranking
- Input Validation
